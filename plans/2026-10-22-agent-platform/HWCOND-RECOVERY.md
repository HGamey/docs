# hwcond 恢复记录

状态：2026-10-23 宿主实现与验证完成，phonefarm e06e1ff 已通过 code-only 119919776212 并直接推 main，远端同SHA已核对。代码路径、锁频和停充守卫是本批范围；不部署、不改真实锁域、不触碰手机或搬实验数据。

## 持久保存与恢复

`state_dir` 与 lease 使用同一个 PHONEFARM_STATE_DIR / HOME 默认值和绝对路径解析器。缺配置、路径无效、读取或写入失败均明确报错，不回退临时目录；查询路径不创建目录。显式配置为临时存储仍由操作者负责，不将其宣称为持久介质。

`lock_state_path` 要求已绑定的非空 serial，保留纯字母数字设备的旧文件名，其他 UTF-8 字节按百分号编码，避免旧下划线替换使不同设备共用记录。发现当前根里的旧有损文件名，或本进程系统临时目录、/tmp 中该设备的旧回退记录时，报出路径并保留原件，要求核对原设备及恢复来源；未绑定设备的旧 default 记录也阻断，不自动套到当前手机。不自动搬移、改名或删除。无法枚举历史自定义 TMPDIR，升级时仍须检查旧运行配置。

状态采用独占创建、完整写入、文件与相关目录同步后才修改设备。已有恢复记录绝不覆盖。新记录有 `phonefarm-recovery@1 <正文UTF-8字节数>` 首行，检测写入中断，包括恰好断在完整行之间；兼容严格解析的旧纯文本，但旧格式本身无法证明完整行未丢失。创建过程中中断留下的记录阻断下一次写入，不能当作没有遗留。无需额外临时副本或内容 hash。

仅 NotFound 表示没有记录。非普通文件、不可读、格式不完整或不受支持的节点/值返回明确错误并保留。锁频恢复使用严格恢复解析，不沿用容错遥测解析的默认值。恢复须回读原节点身份及值，成功并完成记录删除同步才报告成功；停充候选无效时也须核对回滚，失败即停，不尝试下一节点。失败信息不能称“已回滚”。

## 调用方与可见结果

路径接口为 `Result<PathBuf,String>`，恢复为 `Result<Option<bool>,String>`；None 是没有遗留，Some(false) 是已尝试但未确认恢复，Err 是记录或持久化错误。bench/gpuop/perfsrc/selftest 在部署和新的设备修改前处理配置与遗留错误。bench 任一轮恢复失败即停止，避免下一轮重新取被污染的基线。已有 CLI/API 作业日志和 selftest 恢复 JSON 保留明确原因及记录路径，网页使用相同作业回执。

本批不等于完整的设备恢复保障：普通进程退出与全局 lease 屏障的关联、producer typed 恢复收据、selftest 设备端充电脚本及其他旁路仍在 JOB-EXEC-03/LEASE-STORAGE-02。记录保留不等于其他通路自动被全局阻断；后续须逐 producer 接通。宿主模拟无法证明真实断电或设备端停止。
