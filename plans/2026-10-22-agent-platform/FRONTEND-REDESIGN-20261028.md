# 前端重构设计（2026-10-28，用户要求彻底改）

依据：用户反馈（tab 点击跳变、颜色乱变、间距配色差、按钮无反馈、信息量过大、tab 过多且区别不明）+ taste-skill app-screens 规范 + archify。

## 目标结构：5 个 tab（PC 优先）

| tab | 内容（合并自旧页） | 每屏一个问题 |
|---|---|---|
| **main** | 旧「首页」+「实时画面」 | 现在发生了什么：节点在线？设备状态？什么任务在跑？什么在等人？ |
| **device** | 旧「节点与设备」+「远程调试」 | 每台设备在谁手里、什么状态、能不能用 |
| **task** | 旧「任务与结果」+「研究结果」 | 哪个任务要处理：排队/运行/失败/待评价 |
| **agent** | 旧「研究与协助」+ AGENT-02 注册表 + discuss | 每个 agent 在做什么、需要什么协助 |
| **option** | 旧「维护」+「环境诊断」+「节点更新」+「游戏与资源」 | 系统健康与资源管理 |

旧路由保留（不重定向断裂），但导航只露出 5 个；旧页不再进导航。

## 设计规范（taste-skill app-screens 蒸馏）

- **颜色只给数据/状态/一个主操作**：chrome（导航/卡片/边框）无彩色；主色一个（墨蓝 #1F5FBF 延续现有品牌），状态色仅 good/warn/bad 三档；彩色像素占比 ≤5%。
- **KPI 是字不是卡片**：大数字 + 灰标签，无图标、无底色块。
- **平面化**：卡片无阴影，分隔靠 1px 线或一个色阶。
- **无英雄标题**：页面标题 ≤24px，无 "Welcome back"。
- **导航后退**：active 是中性灰 pill 或文字变色，不用彩色块、不用左侧彩条。点击不跳动（固定尺寸）。
- **表格**：1px 行线、无斑马纹、数字右对齐、表头无底色带。
- **诚实状态**：0 显示 0，缺值显示灰色 –，空态保留框架。
- **间距**：8px 基准网格（8/16/24/32），卡片 padding 24px，section 间距 32px。
- **交互反馈**：按钮 hover/active/disabled/busy 四态齐全；操作有回执区（不弹 toast）。
- **密度**：1440×900 首屏显示所有块的标题与首行；长列表 4-6 行 + "查看全部"。

## 外壳（shell）

- 顶栏：左侧产品标（HG 字标 + HGamey 名称 + 当前节点名），中间 5 个 tab（固定宽度 pill），右侧实时时钟 + 登录态 + 退出。
- 顶栏 sticky，背景 = page 色，底部 1px 线，无 backdrop-blur（跳变来源之一）。
- tab pill：固定 min-width、固定 padding；active 用 `--wash` 灰底 + ink 文字加粗；hover 同 wash；**无蓝色块**。
