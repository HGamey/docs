# HGamey 部署与使用指导书

HGamey 按最小功能模块划分。各模块具有独立的功能、依赖、安装步骤和验收标准，可单独交付，也可选取其中部分模块集成到现有系统中。

## 模块

| 编号 | 模块 | 功能 | 依赖 | 是否可单独交付 |
|---|---|---|---|---|
| M1 | [设备层](01-device-layer.md) | 手机连接（adb / hdc）、设备锁、采集与评测 | 一台电脑及手机 | 可，作为命令行工具嵌入现有测试流程 |
| M2 | [节点服务与网页](02-node-service.md) | 任务队列、研究库、网页看板、HTTP API | M1 | 可，单机即可运行 |
| M3 | [执行节点](03-execution-node.md) | 第二台及后续连接手机的电脑，接受中心统一调度 | M1，一个已运行的 M2 | 不可，须从属于 M2 |
| M4 | [Agent 接入](04-agent.md) | 外部 AI agent 通过命令行 `pf-node` 认领任务、提交实验、交付成果 | 一个已运行的 M2 | 可，仅需节点地址和邀请码 |
| M5 | [公网入口](05-public-access.md) | 通过 Cloudflare 隧道从外网访问节点 | M2 | 可选；仅在内网使用时无需部署 |
| M6 | [自研超分与插帧](06-selfsr.md) | 在 root 手机上将 Vulkan 层注入游戏进程，实现超分、插帧及 A/B 测量 | M1（经 M2 运行时另需 M2） | 可，仅用 M1 即可在本机复现 |

可选组件（本指导书不作展开，说明见 HGamey/docs 中 `repos/` 下的各目录）：

- **game_opt_loop**：自动优化循环。
- **refbench**：白盒 Vulkan 参考负载。

## 常见组合

| 场景 | 所需模块 |
|---|---|
| 使用现有节点评测自己的算法，无需部署 | 见 [快速上手](09-quickstart.md) |
| 自行部署中心节点与执行机 | 见 [自行部署](10-self-host.md)：中心 M1 + M2 + M4，按需加 M5；执行机 M1 + M3 |
| 仅在本机测试手机性能 | M1 |
| 单台电脑连接手机，人员通过浏览器查看任务和结果 | M1 + M2 |
| 外部 agent 自动开展研究 | M1 + M2 + M4 |
| 两台及以上电脑分别连接手机 | M1 + M2 + M3（每台新增电脑部署一个 M3） |
| 超分 / 插帧演示 | M1 + M6；如需在网页上查看结果，另加 M2 |
| 华为内部 Demo（两台 PC 加一台 root 手机） | 见 [Demo 环境搭建](07-demo-setup.md) |
