# HGamey 部署与使用指导书

HGamey 按最小功能模块拆分。每个模块有独立的作用、依赖、安装步骤和验收标准，可以单独交付，也可以只取其中几个，集成到已有系统里。

## 模块

| 编号 | 模块 | 作用 | 依赖 | 能否单独交付 |
|---|---|---|---|---|
| M1 | [设备层](01-device-layer.md) | 连接手机（adb / hdc），设备锁，采集与评测 | 一台电脑和手机 | 能，作为命令行工具嵌入已有测试流程 |
| M2 | [节点服务与网页](02-node-service.md) | 任务队列、研究库、网页看板、HTTP API | M1 | 能，单机即可运行 |
| M3 | [执行节点](03-execution-node.md) | 第二台及以后的接手机电脑，接受中心调度 | M1，一个已运行的 M2 | 不能，挂在 M2 之下 |
| M4 | [Agent 接入](04-agent.md) | 外部 AI agent 用命令行 `pf-node` 认领任务、提交实验、交付 | 一个已运行的 M2 | 能，只需节点地址和邀请码 |
| M5 | [公网入口](05-public-access.md) | 通过 Cloudflare 隧道从外网访问节点 | M2 | 可选；只在内网用时不需要 |
| M6 | [自研超分与插帧](06-selfsr.md) | 在 root 手机上给游戏挂 Vulkan 层，做超分、插帧及 A/B 测量 | M1（经 M2 运行时还要 M2） | 能，单独用 M1 即可在本机复现 |

可选组件（不在本指导书展开，说明见 HGamey/docs 的 `repos/` 下各目录）：

- **game_opt_loop**：自动优化循环。
- **refbench**：白盒 Vulkan 参考负载。

## 常见组合

| 场景 | 需要的模块 |
|---|---|
| 只在本机测手机性能 | M1 |
| 一台电脑带手机，人在浏览器上看任务和结果 | M1 + M2 |
| 外部 agent 自动做研究 | M1 + M2 + M4 |
| 两台以上电脑分别接手机 | M1 + M2 + M3（每台新电脑一个 M3） |
| 超分 / 插帧演示 | M1 + M6；要在网页上看结果，再加 M2 |
| 华为内部 Demo（两台 PC 加一台 root 手机） | 见 [Demo 环境搭建](07-demo-setup.md) |
